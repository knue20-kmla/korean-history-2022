# PPT 수업 자료를 이 HTML 덱의 새 단원으로 옮기는 작업 순서

2-1 "냉전 체제와 대한민국 정부 수립"(slide s8~s17)을 만들 때 쓴 방법입니다. 다음 단원도 같은 순서로 하면 됩니다.
(예시 스크립트의 경로는 이 컴퓨터 기준이라, 새 컴퓨터에서는 경로만 고쳐서 쓰세요.)

1. **PPT 내용 뽑기** : `.pptx`를 압축 해제(`unzip`)한 뒤 `node pptx-dump.js` → 슬라이드별 글자·도형 위치·그림 파일명이 `dump.txt`로 나옵니다.
   (PPT는 애니메이션으로 글상자가 겹쳐 있어서 위치만으로는 모양을 알 수 없습니다.)
2. **슬라이드를 그림으로 보기** : PowerShell에서 PowerPoint를 불러 `Presentation.Export(폴더, "PNG", 1600, 900)` 로 내보내고 눈으로 확인합니다.
3. **그림 자료 정리** : `ppt/media`의 원본 그림을 `assets/`로 복사하고, 한 장에 여러 자료가 붙어 있으면 `canvas`로 잘라서 따로 만듭니다 (`example-prep_assets.js`). 파일 이름은 단원마다 접두어를 달리합니다(2-1은 `c21-`).
4. **페이지 만들기** : `example-build_pages.js` 처럼 `dg()`(도표), `.cat`(분류), `.points`(번호 목록) 헬퍼로 슬라이드 HTML과 팝업 목록을 만든 뒤, `example-apply.js`로 `lesson17_v2.html`에 끼워 넣고 사이드바 `BUILT_UNITS`도 연결합니다.
5. **확인** : `shot.js` 로 헤드리스 Edge에서 1920×1080 실제 화면을 찍어서 봅니다 (`node shot.js <주소> <폴더> s9,s10 1920 1080 [nav|teacher|popup]`).

## 지켜야 할 규칙
- **한 페이지의 자연 높이는 964px 이하** : 가장 긴 페이지가 전체 확대 비율을 정합니다. 새 페이지가 더 길면 모든 페이지가 같이 작아집니다. (`slideCssH(i)`로 확인)
- 도표(SVG)의 화살표 머리(marker) id는 도표마다 달라야 합니다 (`d10-g`, `d12-b` …). 숨겨진 페이지의 id를 쓰면 화살표 머리가 안 보입니다.
- 지도·사진·사료는 한 팝업에 하나씩. 같은 팝업 키에 여러 장을 묶지 않습니다.
- 문장은 체언 종결 + 줄 단위(▸)로 쓰고, 영어 표현은 쓰지 않습니다.
- 작업은 OneDrive 폴더에서 하고, 끝나면 로컬 폴더로 백업합니다.
